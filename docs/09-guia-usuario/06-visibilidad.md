Tienes control total sobre quién puede acceder a tus colecciones. Cada vitrina puede tener un nivel de visibilidad diferente que puedes cambiar en cualquier momento.

## Niveles de visibilidad

| Nivel de visibilidad | Quién puede acceder | ¿Aparece en "Explorar"? | Notas adicionales |
| :--- | :--- | :--- | :--- |
| **Pública** | Cualquier visitante | Sí | Todo el mundo puede disfrutar de tu colección. |
| **Privada** | Solo tú | No | Oculta al mundo, requiere iniciar sesión con tu cuenta. |
| **Privada con enlace** | Quien tenga el enlace | No | `[PENDIENTE: Esta funcionalidad está actualmente en desarrollo y no disponible en la interfaz]` |
