A continuación resolvemos algunas dudas derivadas de las decisiones de producto y del enfoque del proyecto.

## Dudas comunes

*   **¿Puedo vender mis sets aquí?** No. El sistema carece de pasarelas de pago y opciones logísticas. Es estrictamente un entorno de exhibición.
*   **¿Cómo sé si un set publicado es real y original?** No lo sabes con certeza oficial. No ofrecemos un servicio de verificación ni tasamos las piezas.
*   **¿Puedo usar la aplicación desde el móvil?** Sí, puedes navegar y gestionar tu vitrina usando el navegador de tu móvil, pero no disponemos de aplicación nativa.
*   **¿Cómo contacto con otro coleccionista?** No puedes. Para proteger el anonimato (nuestra propuesta de valor principal), hemos eliminado cualquier tipo de chat o mensajería directa.
*   **¿Puedo dejar un comentario o puntuar una vitrina?** No, actualmente no hay sistemas de reputación, puntuaciones ni comentarios para mantener una experiencia sin presiones sociales.
*   **¿Cómo subastan los sets más raros?** No hay subastas. No participamos ni fomentamos transacciones económicas entre usuarios.
*   **¿Detecta la web qué set estoy subiendo por la foto?** No. El reconocimiento por IA no está implementado; debes rellenar el nombre del set de forma manual.
*   **¿Alguien puede saber dónde vivo si subo una foto desde mi casa?** No. Tu navegador elimina los datos de geolocalización (GPS) de la foto antes de enviarla.
